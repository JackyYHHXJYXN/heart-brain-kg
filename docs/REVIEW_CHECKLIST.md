# 半年复核清单（建议每年 1 月、7 月各一次）

对每个图谱：
- [ ] 搜索主要指南是否有新版（AHA/ACC、ESC、中国相关学会、WHO）。有则更新对应节点，`ref` 写明新版本年份，更新 `REVIEWED`
- [ ] 重点核对：时间窗、剂量、诊断阈值、评分规则、推荐等级
- [ ] `tools/check-links.sh <图谱id>`：404/000 必须修；403/429 用浏览器手动确认
- [ ] 视频直链 `vl` 是否仍可播放；失效的改用检索词 `v`
- [ ] 随机抽 5 个知识点，按“出处 → 数字”核对一遍
- [ ] 手机（iOS Safari、微信内置浏览器、安卓 Chrome）各打开一次首页、详情、图谱、深色模式
- [ ] `node tools/validate.mjs` 零错误；更新 `sw.js` 的 `V`；`--stamp`
- [ ] 发布后检查线上并刷新社交卡片缓存（若封面或标题改了）
