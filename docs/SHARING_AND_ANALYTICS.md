# 二维码与访问统计

## 二维码
```bash
npm install
node tools/make-qr.mjs
python3 tools/make-poster.py stroke-mi "心梗·脑梗知识图谱" "早识别 · 快急救 · 防复发"
```
- `share/qr-<id>.png`：发微信、朋友圈；`share/qr-<id>.svg`：矢量图，打印用（放大不糊）
- `share/poster-<id>.png`：带标题的海报
- 二维码编码的是网址本身，网址不变就永远有效；只为已上线（live）的图谱生成
- 打印张贴时，建议在二维码旁放一行文字网址，扫码失败时可手输
- 目前没有用扫码软件实测解码，发布后请用手机扫一次确认

## 怎么知道有多少人在用
GitHub Pages 本身没有访问统计。可选方案：

| 方案 | 能看到什么 | 代价 |
|---|---|---|
| GitHub 仓库 Insights → Traffic | 仓库页面的访问和克隆，保留 14 天，**不是网站访客数** | 零；只统计仓库页，不适合衡量用户数 |
| GoatCounter（无 cookie、不收集个人信息） | 访问次数、来源、设备、热门知识点 | 要加载第三方域名，**在中国大陆可能被拦截而少统计**；需要你注册账号；会改变“不引入第三方”的项目约定（CLAUDE.md 第 7 条），必须你明确同意 |
| 自己统计微信/平台后台的分享数据 | 仅限你自己发布的渠道 | 不能覆盖全部 |

结论：不加统计也完全可以运行。如果以后要加，建议只用 GoatCounter 的无脚本图片计数方式，并接受大陆数据偏低。
